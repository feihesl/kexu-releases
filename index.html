本地优先

数据保存在你自己的电脑，不需要注册账号，也不会上传课程、学生和值班信息。

自动更新

启动时检查新版本，下载后校验文件完整性；确认后自动替换并重启。

桌面常驻

悬浮窗、托盘提醒、开机问候和重点人名提示，适合每天上课的节奏。

安装方法

  1. 下载 KeXu-win64.zip。
  2. 解压到任意文件夹。
  3. 双击 安装.cmd，程序会安装到当前用户目录并创建桌面快捷方式。
  4. 以后有新版本时，课序会自动检查并提示更新。

移动版计划

桌面版是 Windows WPF 应用，手机端不能直接复用界面。后续移动版会单独开发跨平台客户端，并配套账号与云同步服务；当前版本继续以本地数据和自动更新为主。

如果 Windows 首次运行提示“未知发布者”，这是因为目前没有购买代码签名证书。可以点击“更多信息 → 仍要运行”。后续版本会逐步完善签名和安装体验。
