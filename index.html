课序 · 上班助手

给老师、培训师和每天要站讲台的人用的本地桌面工作台。
课程表、校历、值班、监考、待办和统计，安静地放在一个窗口里。

今日工作台

下一节课、今日课程、待办、值班、监考、校历大事件和课时统计，打开就能看到。

课程与校历

支持多段周次、单双周、调课和按校历周次显示；新用户自带当前校历。

值班与监考

新用户自带当前值班表；支持导入、点格编辑、重点人名筛选和监考工作量公式。

待办与提醒

截止时间、倒计时、逾期提示、到点提醒，以及桌面悬浮窗和托盘常驻。

数据在本地

不需要账号，不上传课程、学生和值班信息；可更改数据保存位置并自动备份。

使用指引

首次启动会介绍主要功能，可跳过；以后可在「设置 → 关于 → 使用指引」重新查看。

安装方法

  1. 下载 KeXu-win64.zip。
  2. 解压到任意文件夹。
  3. 双击 安装.cmd，按提示安装；也可以直接运行 课序.exe。
  4. 第一次运行会自动创建快捷方式。
  5. 以后有新版本时，课序会自动检查并提示更新。
当前版本支持 Excel(.xlsx / .xls) 导入课程表、校历、值班、监考和班级名单。图片、PDF 和 Word 识别率不稳定，已暂停导入。课程、校历和值班都可以手动编辑。

系统与平台

需要 Windows 10 / 11，系统自带 .NET Framework 4.8。当前版本是 Windows 桌面程序，暂不支持 macOS 原生运行；Mac 用户可以在 Windows 虚拟机中使用。数据默认保存在 %APPDATA%\KeXu，可在设置中更改位置。
